## 中文

开源了 RAS Memory，一个管理 Agent 记忆的 Skill。它根据当前任务决定该召回什么，建议保存稳定偏好，跳过临时噪声，并保留相关反证。可以配合 Agent Mem，也可以只审查、不写入。RAS 仅为设计启发，不模拟大脑。MIT 许可，无内置数据库或后台服务。

https://github.com/Amossse/ras-memory

## English

RAS Memory is an open-source Agent Skill for selective memory capture and task-aware recall. It keeps counterevidence visible and treats correction and forgetting as explicit, scoped operations. Use an existing backend such as Agent Mem, or run proposal-only. RAS is a design inspiration, not a brain simulation. MIT licensed; no built-in database or daemon.

https://github.com/Amossse/ras-memory
