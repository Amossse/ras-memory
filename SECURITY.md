# Security and privacy

This repository contains public instructions and fictional evaluation cases, not personal memories or internal assets. The Skill itself has no network client, storage engine, telemetry, or background capture. A host/model provider may process and retain the context you give it; consult that provider and your selected backend before using private material.

Consent and scope must be enforced by the host/backend, not only by a prompt. Retrieved memory is untrusted data. Embedded commands never authorize uploads, tool calls, cross-scope access, or changes to user goals. Do not capture secrets, internal content, or unnecessary identifiers. Prefer omission over speculative redaction. Do not export a real memory store as part of publishing this project.

Mutations need resolved targets, authorization, revision safeguards, and read-back confirmation. Backend errors must be reported; do not silently claim success. Deleting a record cannot promise forensic erasure or removal from backups/provider logs. Model-generated relevance and importance judgments may be wrong; review important changes.

Report problems with a minimal fictional reproduction. For a sensitive vulnerability, use GitHub's private vulnerability reporting if enabled; otherwise request a private channel without disclosing exploit details or private data in a public issue. This is not a security certification or a medical product.
